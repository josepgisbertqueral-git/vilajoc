BodyMovementTracker\n\n# Create tracker\ntracker = BodyMovementTracker(buffer_size=30, fps=30.0, use_3d=True)\n\n# Update with pose\nmovements = tracker.update(pose_result)  # Dict[int, BodyMovement]\n\n# Access movement data\nfor person_id, movement in movements.items():\n    # Position\n    movement.center_x        # 0-1 normalized\n    movement.center_y        # 0-1 normalized\n    movement.center_z        # Optional 3D\n    \n    # Velocity\n    movement.velocity_x      # pixels/sec\n    movement.velocity_y      # pixels/sec\n    movement.velocity_z      # Optional\n    movement.velocity_magnitude  # Total speed\n    \n    # Direction\n    movement.direction_angle # 0-360 degrees\n    movement.direction_x     # Normalized -1 to 1\n    movement.direction_y     # Normalized -1 to 1\n    movement.direction_z     # Optional\n\n# Get specific person\nmovement = tracker.get_latest_movement(person_id)\n\n# Get all movements\nall_movements = tracker.get_all_movements()\n\n# Export as JSON\njson_data = tracker.get_movements_json()\n\n# Export individual\ndict_data = movement.to_dict()\ncompact = movement.to_compact_dict()\n\n# Reset\ntracker.clear()\n\n# Update FPS\ntracker.set_fps(60)\n```\n\n---\n\n## 🚀 Next Steps\n\n1. **Run demo:** `python demos/export_movement_data.py`\n2. **Check data:** Look at the JSON output\n3.
